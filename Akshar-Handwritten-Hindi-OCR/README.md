# Akshar-Handwritten-Hindi-OCR

> Handwritten Hindi OCR for gov forms

![Stack](https://img.shields.io/badge/stack-Python,%20FastAPI-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
Gov forms need 3-5 days digitization.

### Solution
Handwritten Hindi OCR for gov forms
**Tech:** Stroke heuristic

### Quick Start
```bash
git clone https://github.com/kv-creates/Akshar-Handwritten-Hindi-OCR.git
cd Akshar-Handwritten-Hindi-OCR
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t akshar-handwritten-hindi-ocr .`
