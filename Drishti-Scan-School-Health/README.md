# Drishti-Scan-School-Health

> School health scanner via webcam

![Stack](https://img.shields.io/badge/stack-Python,%20FastAPI-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
70% vision/hearing issues undetected till Class 5.

### Solution
School health scanner via webcam
**Tech:** E-chart, audiometry

### Quick Start
```bash
git clone https://github.com/kv-creates/Drishti-Scan-School-Health.git
cd Drishti-Scan-School-Health
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t drishti-scan-school-health .`
