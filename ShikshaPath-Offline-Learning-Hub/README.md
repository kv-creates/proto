# ShikshaPath-Offline-Learning-Hub

> Offline-first learning PWA for low-connectivity schools

![Stack](https://img.shields.io/badge/stack-Node,%20PWA-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
65% rural schools have <1 Mbps; students can't stream.

### Solution
Offline-first learning PWA for low-connectivity schools
**Tech:** Workbox, IndexedDB

### Quick Start
```bash
git clone https://github.com/kv-creates/ShikshaPath-Offline-Learning-Hub.git
cd ShikshaPath-Offline-Learning-Hub
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t shikshapath-offline-learning-hub .`
