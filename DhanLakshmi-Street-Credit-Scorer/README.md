# DhanLakshmi-Street-Credit-Scorer

> Alternative credit scorer for vendors

![Stack](https://img.shields.io/badge/stack-Python,%20FastAPI-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
Street vendors denied loans for no CIBIL.

### Solution
Alternative credit scorer for vendors
**Tech:** Sales volatility

### Quick Start
```bash
git clone https://github.com/kv-creates/DhanLakshmi-Street-Credit-Scorer.git
cd DhanLakshmi-Street-Credit-Scorer
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t dhanlakshmi-street-credit-scorer .`
