# SaathiSuraksha-Companion-Mesh

> Companion matching + mesh SOS

![Stack](https://img.shields.io/badge/stack-Node-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
Women avoid night travel due to isolation.

### Solution
Companion matching + mesh SOS
**Tech:** Gale-Shapley, BLE mesh

### Quick Start
```bash
git clone https://github.com/kv-creates/SaathiSuraksha-Companion-Mesh.git
cd SaathiSuraksha-Companion-Mesh
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t saathisuraksha-companion-mesh .`
