# VidyaDhan-Scholarship-Matcher

> Scholarship matcher for students

![Stack](https://img.shields.io/badge/stack-Node-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
Rs 2000 Cr scholarships lapse yearly.

### Solution
Scholarship matcher for students
**Tech:** Eligibility tree

### Quick Start
```bash
git clone https://github.com/kv-creates/VidyaDhan-Scholarship-Matcher.git
cd VidyaDhan-Scholarship-Matcher
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t vidyadhan-scholarship-matcher .`
