# NyayMitra-RTI-Drafter

> RTI application drafter + tracker

![Stack](https://img.shields.io/badge/stack-Python,%20FastAPI-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
RTI filing fails for 60% first-timers due to wrong PIO.

### Solution
RTI application drafter + tracker
**Tech:** PIO directory, template engine

### Quick Start
```bash
git clone https://github.com/kv-creates/NyayMitra-RTI-Drafter.git
cd NyayMitra-RTI-Drafter
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t nyaymitra-rti-drafter .`
