# KrishiDhwani-Pest-Acoustic-Guard

> Edge acoustic pest detection for small farms

![Stack](https://img.shields.io/badge/stack-Python,%20FastAPI-blue)
![License](https://img.shields.io/badge/license-MIT-green)

### Problem
Small farmers lose 15-25% yield to pests; manual scouting misses early infestation.

### Solution
Edge acoustic pest detection for small farms
**Tech:** MFCC mock, pest classifier

### Quick Start
```bash
git clone https://github.com/kv-creates/KrishiDhwani-Pest-Acoustic-Guard.git
cd KrishiDhwani-Pest-Acoustic-Guard
# python: pip install -r requirements.txt && python -m src.main
# node: npm install && npm test
```

### Tests
`pytest -q` or `npm test`

### Docker
`docker build -t krishidhwani-pest-acoustic-guard .`
